# Privacy Policy — cv-bot

_Last updated: 4 November 2026_

cv-bot is a personal tool used only by its author, Sergio Pujol, to keep track of his own job applications. It is not offered to anyone else.

## What it accesses

With the author's explicit consent, cv-bot uses the Gmail API with the read-only scope (`gmail.readonly`) on the author's own Gmail account. It reads incoming messages only to detect replies to job applications, such as interview invitations, rejections or offers.

cv-bot cannot send, delete or modify emails.

## How the data is used and stored

- Message data is processed on the author's own computer and is used only to suggest status updates for his job applications. Each suggestion needs his approval.
- To classify a reply, the relevant message text may be sent to the AI model provider the author uses (Anthropic's Claude) under his own account. It is used only for that classification.
- Only the minimum needed is kept locally: the sender, the subject, the date and the detected status. Message bodies are not stored.
- No data is sold, shared with third parties or used for advertising.
- Access can be revoked at any time from the Google Account permissions page (https://myaccount.google.com/permissions).

## Google API Services User Data Policy

cv-bot's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
